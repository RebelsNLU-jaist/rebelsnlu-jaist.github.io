Github Pages for Reading Between the Lines NLU (RebelsNLU) team at JAIST.

## Local preview

```sh
# bundle install
# bundle exec jekyll serve --host 127.0.0.1 --port 4000

# not compatible with ruby 3.4.1
# cd /Users/USRNAME/PROJ_DIR/rebelsnlu-jaist.github.io
cd /Users/houjing/projects/lab_website/rebelsnlu-jaist.github.io
/usr/bin/gem install --user-install bundler -v 2.3.15
BUNDLE_PATH=/private/tmp/rebelsnlu-bundle /usr/bin/bundle _2.3.15_ install
BUNDLE_PATH=/private/tmp/rebelsnlu-bundle /usr/bin/bundle _2.3.15_ exec jekyll serve --host 127.0.0.1 --port 4000

```

Then open <http://127.0.0.1:4000/>.
